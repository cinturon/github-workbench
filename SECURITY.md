# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately**. Do not file public GitHub issues for:

- Credential or token handling bugs
- Authentication bypasses
- Remote code execution via Git, GitHub API, or workflow dispatch
- Secrets leakage in logs, journals, or UI

Contact the maintainers directly (replace with your channel when published). Until then, use the repository's private security advisory feature if available.

## What to include

- Description of the issue and potential impact
- Steps to reproduce
- Affected versions or commits
- Suggested fix (optional)

We will acknowledge receipt and work on a fix before public disclosure.
